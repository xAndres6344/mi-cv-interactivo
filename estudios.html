🌐 Desarrollo de Aplicaciones Web (DAW)

Grado Superior especializado en el desarrollo integral de aplicaciones y sitios web, abarcando tanto el desarrollo frontend como backend. Durante esta formación profundicé en programación, diseño de interfaces, bases de datos, desarrollo de servicios web y despliegue de aplicaciones, adquiriendo una visión completa del ciclo de desarrollo de una aplicación web.

📚 Asignaturas y áreas principales

  • Desarrollo web en entorno cliente: Creación de interfaces dinámicas utilizando HTML, CSS y JavaScript.
  • Desarrollo web en entorno servidor: Programación de la lógica de negocio y gestión de aplicaciones backend.
  • Bases de datos: Diseño, creación, consultas y gestión de bases de datos relacionales.
  • Despliegue de aplicaciones web: Configuración de servidores y publicación de aplicaciones en diferentes entornos.
  • Diseño de interfaces web: Creación de interfaces funcionales, responsive y orientadas a la experiencia de usuario.
  • Programación: Desarrollo de aplicaciones utilizando diferentes lenguajes y metodologías.
  • Servicios web: Desarrollo e integración de APIs y comunicación entre diferentes aplicaciones y servicios.

🛠️ Tecnologías y herramientas

  • Frontend: HTML5, CSS3, JavaScript (ES6+) y Angular.
  • Backend: PHP, Node.js y Express.
  • Lenguajes: Java,JavaScript, PHP y Python.
  • Bases de datos: MySQL, PostgreSQL y MongoDB.
  • APIs: Diseño y consumo de APIs REST.
  • Control de versiones: Git y GitHub.
  • Formatos de datos: JSON y XML.
  • Herramientas: Visual Studio Code, Figma y herramientas de desarrollo web.

🧠 Competencias adquiridas

  • Desarrollo completo de aplicaciones web frontend y backend.
  • Diseño y consumo de APIs REST.
  • Creación de interfaces web responsive e intuitivas.
  • Comunicación entre frontend, backend y bases de datos.
  • Programación y estructuración de aplicaciones web.
  • Control de versiones mediante Git y GitHub.
  • Implementación de lógica del lado servidor.
  • Pruebas, depuración y resolución de errores.
  • Diseño y gestión de bases de datos.
  • Adaptación de interfaces a diferentes dispositivos.
  • Integración de diferentes tecnologías dentro de una misma aplicación.
  • Capacidad para analizar problemas y desarrollar soluciones.

📱 Desarrollo de Aplicaciones Multiplataforma (DAM)

Formación de Grado Superior orientada al diseño, desarrollo y mantenimiento de aplicaciones multiplataforma. Durante estos estudios profundicé en programación orientada a objetos, desarrollo de aplicaciones móviles, acceso a bases de datos, servicios backend, APIs y herramientas de desarrollo, adquiriendo una visión global del ciclo de desarrollo de software.

📚 Asignaturas y áreas principales

  • Programación: Desarrollo de aplicaciones mediante programación orientada a objetos, estructuras de datos y resolución de problemas.
  • Bases de datos: Diseño, creación y gestión de bases de datos relacionales y NoSQL.
  • Acceso a datos: Persistencia de información, conexión con bases de datos, ficheros y diferentes fuentes.
  • Desarrollo de interfaces: Diseño y creación de interfaces gráficas para aplicaciones de escritorio y móviles.
  • Programación multimedia y dispositivos móviles: Desarrollo adaptado a dispositivos móviles y diferentes plataformas.
  • Servicios y procesos: Comunicación entre aplicaciones, servicios backend e integración de componentes.
  • Sistemas empresariales: Introducción a herramientas y soluciones orientadas a entornos corporativos.

🛠️ Tecnologías y herramientas

  • Lenguajes: Java, Kotlin, C#, Dart, JavaScript, PHP
  • Desarrollo móvil: Android Studio, Kotlin, Ionic, Flutter/FlutterFlow
  • Backend: Node.js, APIs REST
  • Bases de datos: PostgreSQL, MySQL, MongoDB, Firebase
  • Control de versiones: Git, GitHub
  • Formatos: JSON, XML
  • Entornos: Android Studio, IntelliJ IDEA, Visual Studio Code
  • Herramientas: Figma, ClickUp, Heroku, Google Cloud

🧠 Competencias adquiridas

  • Diseño y desarrollo de aplicaciones multiplataforma.
  • Programación orientada a objetos.
  • Desarrollo de aplicaciones móviles nativas.
  • Diseño y consumo de APIs REST.
  • Integración entre aplicaciones y servicios backend.
  • Diseño, gestión y optimización de bases de datos.
  • Trabajo con bases de datos relacionales y NoSQL.
  • Desarrollo de interfaces gráficas para diferentes dispositivos.
  • Control de versiones mediante Git y GitHub.
  • Pruebas, depuración y resolución de errores.
  • Aplicación de patrones y buenas prácticas de programación.
  • Capacidad para analizar problemas y desarrollar soluciones software.
